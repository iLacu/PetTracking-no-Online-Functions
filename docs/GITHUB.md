# Quellcode-Repository

Der Repository-Inhalt entspricht dem Ordner Quellcode. Keine persoenlichen Sammlungen, Einstellungen, Diagnosen, Paketmitschnitte, Sicherungen, Zugangsdaten, SDK-Dateien oder fertigen EXEs hochladen. Die .gitignore schliesst die lokalen Laufzeit- und Werkzeugordner zusaetzlich aus. Ein Quellcode-ZIP wird vor dem Hochladen entpackt, damit GitHub die Dateien direkt darstellen kann.

LICENSE, NOTICE, THIRD-PARTY-NOTICES.txt und licenses bleiben Bestandteil der Quellen. Der Originalcode und seine Mitwirkenden werden weiterhin genannt. Das eigene Repository macht den Originalentwickler nicht automatisch zum Mitarbeiter; Zugriffsrechte verwaltet der Repository-Besitzer in GitHub.

Ein Push wird ausschliesslich durch den Besitzer bzw. einen bewusst ausgefuehrten Git-Befehl vorgenommen. Die Anwendung nutzt GitHub weder fuer Updates noch fuer Datensynchronisierung. Es gibt keine GitHub Actions oder automatischen Veroeffentlichungen in diesem Quellstand. Die einzige Download-Funktion der Anwendung ist das festgelegte offizielle Npcap-Setup bei Bedarf, siehe README.

Ein frischer Clone benoetigt separat das SDK und den Paketvorrat. Anleitung: BUILDING.md. Die fertige Ausgabe fuer Freunde entsteht anschliessend mit tools/Pack-Friends.ps1; deren Datenordner ist leer.
